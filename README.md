# Jarvis — Siri-Replica Multilingual Personal AI Assistant (Star Edition)

## How to Run Locally (Recommended for Full Microphone & Wake-Word Support)
1. Double-click `jarvis.html` to open it in Google Chrome, Safari, or Microsoft Edge.
2. Allow microphone permissions when prompted so Jarvis can continuously listen for the **"Jarvis"** or **"Hey Jarvis"** wake word.

## How to Get a Public Shareable Web Link (Free in 15 Seconds)
- **Netlify Drop (No account required for instant preview):** Go to https://app.netlify.com/drop and drag-and-drop this folder or `jarvis.html`.
- **GitHub Pages:** Upload `jarvis.html` (renamed to `index.html`) to a GitHub repository and enable GitHub Pages under Settings -> Pages.
- **Vercel:** Run `npx vercel` inside this folder.
